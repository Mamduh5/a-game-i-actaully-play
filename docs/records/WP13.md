#### Findings required before final WP13 approval

1. **`WP13-F1` (Medium · Required before final WP13 approval — `src/profile/profile_store.gd:140-144, 163-167`):** **`_check_identity()` misclassifies a valid-header database with an empty `profile_identity` table as `FAILED` instead of `QUARANTINED`.**
   - **Observed (`adversarial-probe.log` line 100):** Opening a DB with `user_version=1`, `application_id=1095190864`, and an empty `profile_identity` table (`SELECT` returns `SQLITE_OK` with `0` rows, zero `ERROR:` lines) returned `FAILED` instead of `QUARANTINED` (file remained untouched). `_value()` conflates SQL error and `rows.size() != 1` into `null`, and `_check_identity()` checks `not str(connection.get(&"error_message")).is_empty()`, which is always `true` in `godot-sqlite` because `sqlite3_errmsg()` reports `"not an error"` on `SQLITE_OK`.
   - **Required fix:** Check `_query()` directly inside `_check_identity()` to distinguish actual SQL execution errors (`_failure(connection)`) from `rows.size() != 1` or mismatched `profile_id` (`OpenResult.QUARANTINED`), and add a unit regression for an empty `profile_identity` table.

2. **`WP13-F2` (Medium · Required before final WP13 approval — `src/profile/profile_store.gd:88-98, 118-123`):** **Quarantining a foreign `WAL`-mode SQLite database (`user_version=0, application_id=0`, unrelated tables) mutates the file on disk before returning `QUARANTINED`.**
   - **Observed (`adversarial-probe.log` lines 129-130):** `foreign_wal_db_quarantined` passed, while `foreign_wal_db_untouched_on_quarantine=false`. `_acquire()` executes `PRAGMA journal_mode=DELETE` at line 95 before `_claim()` inspects `SELECT count(*) FROM sqlite_schema` at line 119, rewriting the foreign database's journal mode on disk before quarantining it.
   - **Required fix:** Pre-check `SELECT count(*) FROM sqlite_schema` for `version == 0` in `_acquire()` before issuing `PRAGMA journal_mode=DELETE` (mirroring the existing pre-check of `_check_identity()` for `version == SCHEMA_VERSION` while keeping the TOCTOU re-check inside `BEGIN IMMEDIATE`), and add a SHA-256 immutability test for a foreign WAL database.
