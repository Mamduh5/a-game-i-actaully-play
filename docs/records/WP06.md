## Signed admission state

Checkpoint `510b1d0219f7f9bb0fe92ee847050eeaacdbe7d2` adds a fixed-size challenge for the original host, run, generation, attempt, purpose, paired guest key and fresh nonce. The in-memory seat owner issues scoped invitation tokens, compares credential digests in constant time, expires bounded pending attempts and publishes control only after signature verification. Reclaim rotates the credential and invalidates competing attempts. A lost acceptance can retry with the preceding credential and a fresh signature until the new controller acknowledges. Unit tests cover a wrong or expired invitation, a replayed signature, an uninitialized seat, generation rejection, competing claims and fencing.
