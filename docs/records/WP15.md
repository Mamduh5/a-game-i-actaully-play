## Authoring and provenance

Codex authored the original functional waystone and alternate with the pinned Aseprite 1.3.18.6 batch interpreter. The master generator and two transparent layered `.aseprite` files live under `dev/fixtures/asset_pipeline/source/`. Each uses sRGB and separately editable ground shadow, graphite stone and watercolor layers. Master SHA-256 values are `cb82928c2d1ae3485c5f709f7e8b55716e280c0d3ce192741a356b0673cda9cb` for the original and `73200c0f7c92491e9f837e414e1189e5c0861371feedbdb28fa9474dbd92f756` for the alternate. Their combined size is about 31 KB, so the fixture paths use ordinary Git.

`derive.ps1` exports the three-frame 216 × 88 RGBA atlases and Aseprite's frame/tag JSON. The script contains the authored two-tone source for the cue and encodes it with FFmpeg 8.1. Godot source-adjacent imports and authored SpriteFrames specify linear filtering in the view, lossless textures and frame-bound clipping. Resizing or replacing the art leaves fixture contact and tell geometry independent. [Aseprite export docs](https://aseprite.org/docs/cli/)

The example uses one pixel per logical unit, a 72 × 88 frame, a foot anchor at (36,70) and a rune socket at (−1,−28) from the foot. The `VisualAsset` resource carries stable visual ID, frame and scale metadata, facing, sockets, layer and occlusion intent. Asset IDs identify presentation variants independently of game definition IDs. The example and its timings are fixture parameters. Content writers supply their own GDS timings and geometry.

## Reproduction and verdict

Use pinned Windows Godot `4.7.stable.official.5b4e0cb0f`, Compatibility, Aseprite `1.3.18.6` and FFmpeg/FFprobe `8.1`. The clean-candidate rendered capture used a 1280 × 720 viewport, NVIDIA RTX 3060, linear sampling and WASAPI. Use a fresh checkout and an existing disposable capture directory for `O`.

```text
powershell -NoProfile -ExecutionPolicy Bypass -File dev/fixtures/asset_pipeline/source/derive.ps1 -Aseprite <pinned-aseprite-exe>
G --headless --editor --path P --import
G --path P res://dev/fixtures/asset_pipeline/asset_fixture.tscn -- --wp15-capture=O
ffprobe -v error -of json -show_entries stream=codec_name,sample_rate,channels:format=duration dev/fixtures/asset_pipeline/derived/waystone_cue.ogg
ffmpeg -hide_banner -i dev/fixtures/asset_pipeline/derived/waystone_cue.ogg -af volumedetect -f null NUL
```

Supply `-RegenerateMasters` only when authoring fresh fixture masters from the Lua source. To inspect interactively, launch the fixture with no user arguments and use **Swap artwork**, **Geometry overlay** and **Play cue**.
